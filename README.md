# Sharetribe Skills

Plugin for non-technical users working on the Sharetribe Web Template.

## What this does

Gives you a guided assistant inside to work with the template. Type `/sharetribe:start` to access the following skills:

- Setting up the template for the first time
- Setting up a staging environment
- Committing your changes and deploying them to staging
- Building a new feature or customization

## Usage

```
/sharetribe:start
```
